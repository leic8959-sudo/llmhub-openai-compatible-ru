# Безопасность

Не публикуйте в Issues, Pull Requests и логах:

- API-ключи и токены;
- содержимое `.env`;
- персональные данные и исходные документы пользователей;
- приватные URL личного кабинета;
- полные ответы, если они содержат закрытые данные.

Для сообщений об уязвимостях используйте приватный канал поддержки LLMHub, а
не публичный Issue. Перед отправкой приложите минимальный воспроизводимый
пример без секретов.
